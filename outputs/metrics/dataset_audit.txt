      * angle_of_asymmetry_degree

3. FILENAME CONVENTIONS & LOCAL DOCUMENTATION INSPECTION
----------------------------------------
Naming Syntax for Environment 4:
  Pattern: [Subject].[Task] [Camera_View] [Trial_Number]_anonymized.mp4
  Components:
    - Subject Identifier : Single uppercase letter ('A.', 'B.', 'C.', 'D.')
    - Task Direction     :
        * TERRA-CARRIOLA : Ground to Wheelbarrow (Manual lifting phase)
        * CARRIOLA-TERRA : Wheelbarrow to Ground (Manual lowering phase)
    - Camera Perspective :
        * LAT            : Laterale (Lateral sagittal-plane perspective)
        * 3quarti        : Tre Quarti (Three-quarters oblique perspective)
    - Trial Number       : Integer index (1, 2, 3, 4, 5, 6)
    - Processing Marker  : '_anonymized' (Denotes face-blurring for subject privacy)
    - Extension          : .mp4
  Annotation vs Disk Mapping:
    - annotations.json references the un-anonymized master filename (e.g., 'A. TERRA-CARRIOLA LAT 1.mp4')
    - Extracted files on disk have the '_anonymized' token (e.g., 'A. TERRA-CARRIOLA LAT 1_anonymized.mp4')
    - Mapping is exact, deterministic, and bijective (1-to-1).
